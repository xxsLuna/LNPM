# Security policy

## Supported versions

Security fixes are provided for the latest published LNPM release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not disclose exploitable details, private network addresses, or database contents in a public issue.

Include the affected version, operating system, impact, reproduction steps, and any proposed mitigation. Acknowledgement and remediation timelines depend on severity and maintainer availability.
