# LNPM

LNPM is a cross-platform live ICMP latency and network stability monitor for Windows, macOS, and Linux.

It continuously records round-trip latency for multiple targets, highlights outages and unstable periods, and provides tray and historical chart views.

## Development

Prerequisites:

- Rust stable toolchain
- Node.js 22 or newer
- pnpm 10 or newer
- Platform prerequisites required by Tauri 2

```powershell
pnpm install
pnpm tauri dev
```
